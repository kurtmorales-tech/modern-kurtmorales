# Kurt Morales Portfolio

JavaScript portfolio site for Kurt Anthony Morales.

## Theme

Bold modern technology theme using:

- Electric Blue: `#0066ff`
- Neon Cyan: `#00ffff`
- Dark Gray: `#1e1e1e`
- White: `#ffffff`
- Ice Blue: `#d4e4f7`
- Steel Blue: `#4a6fa5`
- Silver: `#c0c0c0`
- Crisp White: `#fafafa`

No purple gradient UI is used.

## Files

- `index.html`
- `styles.css`
- `script.js`
- `_headers`
- `README.md`

## Deploy to Cloudflare Pages

1. Upload these files to a GitHub repository.
2. Open Cloudflare Dashboard.
3. Go to Workers & Pages > Pages.
4. Connect the GitHub repository.
5. Build settings:
   - Framework preset: None
   - Build command: leave blank
   - Output directory: `/`
6. Deploy.

## Local Preview

Open `index.html` in a browser.
